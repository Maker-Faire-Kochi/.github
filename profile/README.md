# Maker Faire Kochi

**Kerala's first licensed Maker Faire** — a festival of invention, creativity and hands-on learning.

📅 **26–27 January 2027** · 📍 Kochi, Kerala · 🎟️ Free and open to the public
🌐 **[makerfaire.in](https://makerfaire.in)**

Built together by **TinkerHub Foundation**, **MakerGram** and **Kerala Startup Mission**, giving Kerala's labs, campuses and maker communities a shared public stage.

## What lives in this organization

This organization is the single home for **everything Maker Faire Kochi** — the work is done in the open, in one place:

- **Website** — the code behind [makerfaire.in](https://makerfaire.in)
- **Finance** — budgets, sponsorship and funding, expenses, and accounts
- **Operations** — planning, venue, logistics, schedules and volunteers
- **Sponsors & partners** — outreach, agreements and deliverables
- **Makers & exhibitors** — calls, applications and the Kerala Maker Directory
- **Media & design** — brand assets, content, photography and film
- **Community** — interest forms, volunteers and roadshow updates

If it is part of Maker Faire, it is tracked here, **including finance**.
